# 🌾 AI-Based Crop Disease Detection System

## 🚀 Overview

This project is an **AI-powered crop disease detection and recommendation system** that analyzes leaf images using computer vision. It helps farmers and agronomists identify plant diseases early and provides treatment suggestions in real time.

The system supports image input from **mobile cameras or drones** and runs as a **local web application**.

## 🎯 Problem Statement

Farmers often struggle to detect crop diseases early, leading to reduced yield and financial loss. Manual inspection is time-consuming and requires expertise.

This project solves the problem by providing:
- Automated disease detection
- Cause analysis
- Treatment recommendations
- Field-level disease estimation

## 💡 Solution
- 📷 Accepts leaf images (mobile/drone)
- 🤖 Uses AI to detect disease
- 🧠 Analyzes cause and severity
- 💊 Recommends treatment (chemical + dosage)
- 🚁 Estimates field spread using drone simulation
- 🌐 Supports multi-language output
- 📄 Generates downloadable reports
- 🎮 Includes 3D visualization for better understanding
